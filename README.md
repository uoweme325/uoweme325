## Open-Source Projects

### [AirPlayTray](https://github.com/uoweme325/AirPlayTray) — Stream Windows PC Audio to HomePod / AirPlay 2
- **What it solves:** An open-source **TuneBlade alternative** when legacy AirPlay 1 audio streaming fails on HomePod OS 27 and recent firmware updates.
- **Key features:** Windows WASAPI loopback system audio capture (no virtual audio cable needed), AirPlay 2 streaming via `pyatv`, portable Windows x64 build (`.exe` / no Python needed), speaker picker tray menu, and automatic idle speaker release.
- **中文简介：** 开源免费的 **TuneBlade 替代方案**，将 Windows 10/11 电脑系统声音实时投送到 HomePod / HomePod mini / AirPlay 2 音箱，支持便携免安装运行与静音自动待机释放。
- **Links:** [GitHub Repo](https://github.com/uoweme325/AirPlayTray) · [Project Page](https://uoweme325.github.io/AirPlayTray/) · [Latest Release](https://github.com/uoweme325/AirPlayTray/releases/latest)

### [AgentPet](https://github.com/uoweme325/AgentPet) — Windows Desktop Pet for AI Coding Agents
- **What it does:** A lightweight Windows desktop companion (PowerShell + WPF) that shows live working states, **Codex** quota status, and **DeepSeek Harness (DSH)** balance details for **Antigravity, Codex, and DeepSeek Harness** workflows.
- **Key features:** Anime-style companion characters (小克 / Claude娘, 白龙 / GPT娘, 双子 / Gemini娘), interactive status bubble boards, low-balance reminders, system tray controls, and portable Windows release.
- **中文简介：** 面向 **Antigravity（反重力）、Codex 与 DeepSeek Harness（DSH）** 的 Windows 桌面桌宠，支持实时状态气泡联动、Codex 额度与 DeepSeek 余额看板展示，免安装便携启动。
- **Links:** [GitHub Repo](https://github.com/uoweme325/AgentPet) · [Latest Release](https://github.com/uoweme325/AgentPet/releases/latest)
